# 公司HR制度 - 年假与休假管理

## 第一章 年假制度

### 第一条 适用范围
本制度适用于公司全体正式员工，试用期员工不享受年假。

### 第二条 年假天数标准
年假天数根据员工在本公司的连续工龄确定：

| 工龄 | 年假天数 |
|------|----------|
| 1-3年 | 5天 |
| 3-5年 | 8天 |
| 5-10年 | 10天 |
| 10-20年 | 15天 |
| 20年以上 | 20天 |

### 第三条 年假申请流程
1. 员工需提前至少3个工作日通过OA系统提交年假申请。
2. 申请需经直属领导审批，超过5天的年假需部门负责人加签。
3. 审批通过后，年假记录自动同步到考勤系统。
4. 年假最小申请单位为0.5天。

### 第四条 年假有效期
当年年假应在次年3月31日前使用完毕，逾期未用的年假自动作废，不折算工资。

### 第五条 特殊规定
- 婚假：员工结婚可享受3天婚假，需提供结婚证复印件。
- 丧假：直系亲属去世可享受3天丧假。
- 产假/陪产假：按国家及地方相关规定执行。

## 第二章 病假与事假

### 第六条 病假申请
1. 员工因病需要请假，需在当日上午9:00前通过OA系统提交病假申请。
2. 超过3天的连续病假需提供医院开具的病假证明。

### 第七条 事假申请
事假为无薪假，员工每年累计事假不得超过15天。
