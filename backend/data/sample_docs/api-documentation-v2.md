# 开放API接口说明文档 v2.1

## 一、概述

公司开放API为合作伙伴提供标准化的数据接口，支持RESTful调用。
API基础地址：`https://api.example.com/v2`

## 二、认证方式

所有API调用需在HTTP Header中携带API Key：
```
Authorization: Bearer {YOUR_API_KEY}
```

## 三、速率限制

| 套餐等级 | 速率限制 | 月度额度 |
|----------|----------|----------|
| 免费版 | 60次/分钟 | 10,000次/月 |
| 基础版 | 300次/分钟 | 100,000次/月 |
| 专业版 | 1,000次/分钟 | 1,000,000次/月 |
| 企业版 | 5,000次/分钟 | 10,000,000次/月 |

超出速率限制的请求将返回HTTP 429 (Too Many Requests)状态码。
建议客户端实现指数退避重试策略。

## 四、主要接口

### 4.1 文档搜索接口
```
GET /v2/documents/search?q={keyword}&page={page}&size={size}
```
- `q`：搜索关键词，必填
- `page`：页码，从1开始，默认1
- `size`：每页条数，默认20，最大100

### 4.2 文档详情接口
```
GET /v2/documents/{document_id}
```

### 4.3 批量查询接口
```
POST /v2/documents/batch
Content-Type: application/json

{
  "ids": ["doc-001", "doc-002", "doc-003"]
}
```
单次最多查询100个文档ID。

## 五、错误码说明

| HTTP状态码 | 说明 |
|------------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | API Key无效或已过期 |
| 429 | 超出速率限制 |
| 500 | 服务器内部错误 |

## 六、版本策略

API遵循语义化版本规范（SemVer）。主版本号变更可能包含不兼容的接口修改，次版本号变更为向后兼容的功能新增。
当前版本v2.1于2024年6月发布。
